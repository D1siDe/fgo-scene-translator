# FGO Scene Translator

[English](README.md) · **Русский**

Неофициальный инструмент для установки перевода сюжетных сцен Fate/Grand Order (JP) на Android **без перепаковки APK** и без повторного входа в аккаунт. Язык перевода любой, который поддерживает шрифт игры (переводы и примеры в проекте русские). Интерфейс приложения доступен на русском и английском.

> Проект не связан с Aniplex, Sony Music Entertainment (Japan), Lasengle и TYPE-MOON. В репозитории нет файлов игры, ключей шифрования и стороннего ПО: всё это нужно получить самостоятельно, имея установленную игру. Используйте на свой риск: изменение файлов игры может нарушать условия сервиса.

## Как это работает

Сервер на ПК (Python) расшифровывает файлы сюжета, подставляет перевод и подгоняет контрольную сумму CRC32 под оригинал. Приложение на телефоне через [Shizuku](https://shizuku.rikka.app/) читает и записывает файлы в `Android/data` игры и общается с сервером по Wi-Fi или USB.

```
игра → «Передать главы на ПК» → ПК: расшифрованные сцены → вы переводите → «Установить перевод» → игра
```

Файлы глав подменяются на лету, перевод переживает обновления игры (после обновления достаточно снова нажать «Установить перевод»). Кнопка «Проверить обновления» сообщает, что глава изменилась или появился новый перевод.

## Быстрый старт (готовый APK)

**На телефоне**

1. Скачайте `FGO-Scene-Translator-*.apk` из [Releases](../../releases) (ARM64) и установите.
2. Установите и запустите [Shizuku](https://shizuku.rikka.app/) (Android 11+, беспроводная отладка).
3. Откройте в игре любую главу, чтобы скачался её сценарий.

**На ПК** (Windows, PowerShell)

1. Установите Python 3.11, зависимости и скачайте репозиторий:

   ```powershell
   python -m pip install flask requests UnityPy lz4
   git clone https://github.com/D1siDe/fgo-scene-translator.git
   cd fgo-scene-translator
   ```

2. Положите ключи шифрования бандлов FGO (`assetbundleKey.json`, `AssetListWithExtraKeyType.json`) в папку `external_decryptor/`. Путь и структуру см. в начале `server.py` (`KEYS_JSON`, `EXTRA_JSON`). Ключи в репозиторий не входят.
3. Запустите сервер (для Wi-Fi он должен слушать все интерфейсы, а брандмауэр должен пропускать порт 5000):

   ```powershell
   chcp 65001; $env:PYTHONUTF8 = 1
   $env:FGO_HOST = "0.0.0.0"
   New-NetFirewallRule -DisplayName "FGO Scene Translator" -Direction Inbound -Protocol TCP -LocalPort 5000 -Action Allow   # один раз, от администратора
   python server.py
   ```

   Вариант по USB: не задавайте `FGO_HOST`, выполните `adb reverse tcp:5000 tcp:5000` и укажите в приложении `http://127.0.0.1:5000`.

**В приложении**

1. Введите адрес сервера (`http://<IP ПК>:5000`), нажмите **Проверить сервер**, затем **Проверить Shizuku**.
2. Нажмите **Передать главы на ПК**. Сервер сохранит и расшифрует скачанные вами главы.
3. Переведите сцены (см. ниже).
4. Нажмите **Установить перевод** и запустите игру.
5. После обновления игры или нового перевода: **Проверить обновления**, затем снова **Установить перевод**.
6. **Вернуть оригиналы** возвращает исходные файлы.

В свёрнутом блоке «Режим эмулятора» те же действия выполняет ПК через adb. Он нужен только для эмуляторов.

## Формат перевода

Перевод — это **оригинальный файл сцены с заменённым текстом**. Ничего не склеивается из двух файлов.

1. После **«Передать главы на ПК»** расшифрованные сцены лежат в `scripts_ja/`, в подпапке на каждый бандл главы (например `scripts_ja/ScriptActionEncrypt_02/0200020010.txt`).
2. Скопируйте нужную сцену в папку переводов (`translations/scenarios/`, меняется переменной `FGO_TRANSLATIONS`) и замените японский текст своим переводом. Имя файла не меняйте.
3. Всё остальное оставьте как есть: команды сцены, строки говорящего (`＠имя`) и теги внутри реплик (`[r]`, `[%1]`, `[&а:б]`). Строки выбора имеют вид `？N：текст`, переводится текст после двоеточия.
4. Переносы строк расставляются автоматически: сервер подгоняет текст под окно диалога (по умолчанию ширина 34, 2 строки).

Сервер подхватывает новые и изменённые файлы, собирает бандл главы на лету и отдаёт его телефону. Сцена без файла перевода остаётся на японском.

`scene_tool.py` — необязательный помощник: он выгружает сцены в удобные рабочие файлы, проверяет, что теги не потерялись, и сам собирает файл перевода. Если вы правите файлы сцен напрямую, он не нужен.

Перенос строк рассчитан на латиницу и кириллицу. Для других языков измените `FGO_WRAP_WIDTH` и `FGO_WRAP_LINES` и убедитесь, что в шрифте игры есть нужные символы.

## Переменные окружения

| Переменная | По умолчанию | Назначение |
| --- | --- | --- |
| `FGO_HOST` | `127.0.0.1` | Адрес, на котором слушает сервер (`0.0.0.0` для Wi-Fi) |
| `FGO_ADB_SERIAL` | `127.0.0.1:16384` | Устройство для режима adb |
| `FGO_TRANSLATIONS` | `translations/scenarios` | Папка с переводами |
| `FGO_DATA_DIR` | рядом со скриптами | Папка данных: `collected/` (файлы с телефона), `scripts_ja/` (расшифрованные сцены), `work/` (рабочие файлы `scene_tool.py`) |
| `FGO_WRAP`, `FGO_WRAP_WIDTH`, `FGO_WRAP_LINES` | `1`, `34`, `2` | Автоматический перенос строк |

## Состав

| Путь | Назначение |
| --- | --- |
| `server.py`, `core/` | Сервер: расшифровка, сборка перевода, подгонка CRC32, перенос строк |
| `scene_tool.py` | Необязательный помощник переводчика: рабочие файлы, проверка тегов |
| `export_scripts.py` | Расшифровка всех переданных глав в `scripts_ja/` |
| `build_pack.py`, `install_pack.py` | Пакетная установка по adb (эмулятор) |
| `FGOPatcher.Maui.csproj`, `MainPage*`, `L.cs`, `PhoneInstaller.cs`, `ShizukuShell.cs`, `Platforms/`, `Resources/`, `libs/` | Приложение для телефона (.NET MAUI) |

## Сборка приложения из исходников

Нужны .NET 8 SDK с нагрузкой `maui-android` и библиотеки Shizuku (`libs/shizuku-*.jar`, версия 13.1.5 из Maven, см. `FGOPatcher.Maui.csproj`).

```powershell
dotnet build -t:Run -f net8.0-android -c Debug -p:AdbTarget="-s <серийник>"
```
